# CRM-4 Marketing Lists and Campaign History Data Dictionary

**Contract:** CRM-4 V1, issue #39 (CRM4-04; approved implementation source of truth).
Domain at issue: Marketing lists have `name` and `description`. Campaigns have `name`, `campaign_date`, and target `list_id`. Members have `campaign_id`, `contact_id`, status `sent`, `opened`, `clicked`, and `unsubscribed` flag. Consent records store `contact_id`, status `subscribed` or `unsubscribed`, `consent_date`, and `source`.

Campaign sending, email/SMS delivery and analytics are strictly out of scope in V1; only campaign history and contact consent states are recorded.

### Non-Negotiable Invariant (BR-CRM4-01)
Opt-out / unsubscribe is strictly monotonic. Once a contact is marked as `unsubscribed`, no import, bulk update, or campaign activity may overwrite or revert that status to `subscribed`.

All timestamps are PostgreSQL `timestamptz` in UTC. UUIDs are generated by PostgreSQL (`gen_random_uuid()`). The owner for every object below is the CRM-4 module; cross-module relationships access data through owning APIs or approved read-only projections, never by direct cross-schema foreign keys or mutations.

---

## `crm4.crm4_lists`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Marketing list primary key. | CRM-4 | Primary key; generated by `gen_random_uuid()`. |
| `name` | `text` | NOT NULL | Marketing list name. | CRM-4 | Must contain at least one non-whitespace character. |
| `description` | `text` | NULL | Description of the target segment or audience. | CRM-4 | Optional free text. |
| `created_at` | `timestamptz` | NOT NULL | Creation timestamp. | CRM-4 | Defaults to `now()`. |
| `updated_at` | `timestamptz` | NOT NULL | Last modification timestamp. | CRM-4 | Defaults to `now()`. |

Indexes:
- `crm4_lists_name_idx`: B-tree index on `lower(name)`.
- `crm4_lists_created_at_idx`: B-tree index on `created_at DESC`.

---

## `crm4.crm4_campaigns`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Campaign history record primary key. | CRM-4 | Primary key; generated by `gen_random_uuid()`. |
| `name` | `text` | NOT NULL | Name of the recorded campaign. | CRM-4 | Must contain at least one non-whitespace character. |
| `campaign_date` | `date` | NOT NULL | Date on which the campaign was run. | CRM-4 | Valid ISO date (`YYYY-MM-DD`). |
| `list_id` | `uuid` | NOT NULL | Target marketing list identifier. | CRM-4 | Foreign key referencing `crm4.crm4_lists(id)` with `ON DELETE RESTRICT`. |
| `created_at` | `timestamptz` | NOT NULL | Creation timestamp. | CRM-4 | Defaults to `now()`. |
| `updated_at` | `timestamptz` | NOT NULL | Last modification timestamp. | CRM-4 | Defaults to `now()`. |

Indexes:
- `crm4_campaigns_list_id_idx`: B-tree index on `list_id`.
- `crm4_campaigns_date_idx`: B-tree index on `campaign_date DESC`.

---

## `crm4.crm4_members`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Campaign member activity primary key. | CRM-4 | Primary key; generated by `gen_random_uuid()`. |
| `campaign_id` | `uuid` | NOT NULL | Associated campaign record. | CRM-4 | Foreign key referencing `crm4.crm4_campaigns(id)` with `ON DELETE CASCADE`. |
| `contact_id` | `uuid` | NOT NULL | CRM-1 contact reference. | CRM-4 | Logical reference to CRM-1 contact; verified via ReferenceResolver. |
| `status` | `text` | NOT NULL | Delivery status. | CRM-4 | Must be one of `sent`, `opened`, `clicked`. Default `sent`. |
| `unsubscribed` | `boolean` | NOT NULL | Indicates if recipient opted out during this campaign. | CRM-4 | Default `false`. If `true`, reflected in `crm4_consents`. |
| `created_at` | `timestamptz` | NOT NULL | Member creation timestamp. | CRM-4 | Defaults to `now()`. |

Indexes:
- `crm4_members_campaign_id_idx`: B-tree index on `campaign_id`.
- `crm4_members_contact_id_idx`: B-tree index on `contact_id`.
- `crm4_members_campaign_contact_key`: Unique index on `(campaign_id, contact_id)`.

---

## `crm4.crm4_consents`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Consent record primary key. | CRM-4 | Primary key; generated by `gen_random_uuid()`. |
| `contact_id` | `uuid` | NOT NULL | CRM-1 contact identifier. | CRM-4 | Unique logical reference to contact. |
| `status` | `text` | NOT NULL | Current consent state. | CRM-4 | Must be `subscribed` or `unsubscribed`. Subject to BR-CRM4-01 monotonic check. |
| `consent_date` | `timestamptz` | NOT NULL | Timestamp when consent state was captured. | CRM-4 | Defaults to `now()`. |
| `source` | `text` | NOT NULL | Provenance of the consent update. | CRM-4 | E.g., `web-form`, `csv-migration`, `opt-out-link`. Non-empty. |
| `created_at` | `timestamptz` | NOT NULL | Creation timestamp. | CRM-4 | Defaults to `now()`. |
| `updated_at` | `timestamptz` | NOT NULL | Last modification timestamp. | CRM-4 | Defaults to `now()`. |

Indexes:
- `crm4_consents_contact_id_key`: Unique index on `contact_id`.
- `crm4_consents_status_idx`: B-tree index on `status`.
