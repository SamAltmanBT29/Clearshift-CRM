# CRM-3 Support Tickets and Activities Data Dictionary

**Contract:** CRM-3 V1, issue #26 (CRM3-01; approved implementation source of truth).
Domain at issue: Ticket fields subject, status, priority, contact link, optional order_ref text and note. Status values: `New`, `Open`, `Waiting`, `Solved`, `Closed`; Priority values: `Low`, `Normal`, `High`, `Urgent`. Notes retain author and created_at; ordered newest-first. In V1 `order_ref` is text, not an enforced ERP foreign key. No timeline/SLA in V1.

All timestamps are PostgreSQL `timestamptz` in UTC. UUIDs are generated by PostgreSQL (`gen_random_uuid()`). The owner for every object below is the CRM-3 module; cross-module relationships access data through owning APIs or approved read-only projections, never by direct cross-schema foreign keys or mutations.

---

## `crm3.crm3_tickets`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Support ticket primary key. | CRM-3 | Primary key; generated by `gen_random_uuid()`. |
| `subject` | `text` | NOT NULL | Brief summary or title of the ticket. | CRM-3 | Must contain at least one non-whitespace character. |
| `status` | `text` | NOT NULL | Ticket resolution state. | CRM-3 | Must be one of `New`, `Open`, `Waiting`, `Solved`, `Closed`. Default `New`. |
| `priority` | `text` | NOT NULL | Ticket priority level. | CRM-3 | Must be one of `Low`, `Normal`, `High`, `Urgent`. Default `Normal`. |
| `contact_id` | `uuid` | NOT NULL | Identifier of the customer contact who opened/is linked to the ticket. | CRM-3 | Logical link to CRM-1 contact; no cross-schema FK constraint. |
| `order_ref` | `text` | NULL | Optional commercial order reference number. | CRM-3 | Plain text identifier in V1; not a hard foreign key to ERP. |
| `source_system` | `text` | NULL | Origin system for imported tickets. | CRM-3 | Present together with `source_id`; `(source_system, source_id)` is unique. |
| `source_id` | `text` | NULL | Stable identifier in the origin system. | CRM-3 | Present together with `source_system`; `(source_system, source_id)` is unique. |
| `created_at` | `timestamptz` | NOT NULL | Ticket creation timestamp. | CRM-3 | Defaults to `now()`. Indexed descending. |
| `updated_at` | `timestamptz` | NOT NULL | Last modification timestamp. | CRM-3 | Defaults to `now()`. |

Indexes:
- `crm3_tickets_source_key`: Unique `(source_system, source_id)`.
- `crm3_tickets_contact_id_idx`: B-tree index on `contact_id`.
- `crm3_tickets_status_idx`: B-tree index on `status`.
- `crm3_tickets_priority_idx`: B-tree index on `priority`.
- `crm3_tickets_created_at_idx`: B-tree index on `created_at DESC`.

## `crm3.crm3_notes`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Note primary key. | CRM-3 | Primary key; generated by `gen_random_uuid()`. |
| `ticket_id` | `uuid` | NOT NULL | Foreign key referencing the parent ticket. | CRM-3 | Foreign key to `crm3.crm3_tickets(id)` with `ON DELETE CASCADE`. |
| `author_id` | `text` | NOT NULL | Identifier of the note author (user or system agent). | CRM-3 | Must contain at least one non-whitespace character. Populated from authenticated server context. |
| `note_text` | `text` | NOT NULL | Append-only note content. | CRM-3 | Must contain at least one non-whitespace character. |
| `created_at` | `timestamptz` | NOT NULL | Creation timestamp. | CRM-3 | Defaults to `now()`. Deterministic tie-breaker for newest-first sorting. |

Indexes:
- `crm3_notes_ticket_id_idx`: B-tree index on `ticket_id`.
- `crm3_notes_ticket_created_at_idx`: Composite index on `(ticket_id, created_at DESC)`.

## Import Entities (Migration Kit Integration)

### `crm3.crm3_import_batches`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Import batch identifier. | CRM-3 | Primary key; generated by `gen_random_uuid()`. |
| `source_system` | `text` | NOT NULL | Origin system identifier. | CRM-3 | Non-whitespace. |
| `status` | `text` | NOT NULL | Batch processing state. | CRM-3 | `pending`, `processing`, `completed`, or `failed`. Default `pending`. |
| `idempotency_key` | `text` | NULL | Caller-supplied idempotency key. | CRM-3 | Unique when present; paired with `request_hash`. |
| `request_hash` | `text` | NULL | SHA-256 payload digest. | CRM-3 | Paired with `idempotency_key`. |
| `loaded_count` | `integer` | NOT NULL | Accepted rows count. | CRM-3 | Defaults to 0; non-negative check. |
| `rejected_count` | `integer` | NOT NULL | Rejected rows count. | CRM-3 | Defaults to 0; non-negative check. |
| `created_at` | `timestamptz` | NOT NULL | Batch creation timestamp. | CRM-3 | Defaults to `now()`. |
| `updated_at` | `timestamptz` | NOT NULL | Batch update timestamp. | CRM-3 | Defaults to `now()`. |
| `completed_at` | `timestamptz` | NULL | Batch completion timestamp. | CRM-3 | Set upon terminal status. |

### `crm3.crm3_import_receipts`

| Field | PostgreSQL type | Nullability | Meaning | Owner | Constraints |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | Receipt primary key. | CRM-3 | Primary key; generated by `gen_random_uuid()`. |
| `batch_id` | `uuid` | NOT NULL | Owning batch identifier. | CRM-3 | Foreign key to `crm3.crm3_import_batches(id)` on delete cascade. |
| `source_row` | `integer` | NOT NULL | 1-based source row index. | CRM-3 | Check `> 0`. Unique composite key with `(batch_id, source_row, entity)`. |
| `entity` | `text` | NOT NULL | Entity type imported. | CRM-3 | `ticket` or `note`. |
| `source_system` | `text` | NOT NULL | Origin system identifier. | CRM-3 | Non-whitespace. |
| `source_id` | `text` | NOT NULL | Origin record identifier. | CRM-3 | Non-whitespace. |
| `target_id` | `uuid` | NOT NULL | Target entity primary key created. | CRM-3 | UUID; no cross-module FK. |
| `idempotency_key` | `text` | NOT NULL | Stable idempotency key: `batch ID + source row + target entity`. | CRM-3 | Non-whitespace and globally unique. |
| `created_at` | `timestamptz` | NOT NULL | Receipt creation timestamp. | CRM-3 | Defaults to `now()`. |
